# clinical_note_nlp
### Entity Extraction and Structured Summarization of Medical Transcriptions  

*RoboGarden Applied ML Project*
## Project Context
This project was developed as part of an applied machine learning program at RoboGarden. While completed within an academic context, the project emphasizes industry-relevant NLP workflows, evaluation practices, and system-level thinking.


Exploratory NLP project on medical transcriptions, focusing on clinical entity extraction and SOAP-style structured summaries with evaluation and error analysis.
This project explores natural language processing techniques applied to real-world medical transcription data. Using a publicly available clinical dataset, the project focuses on cleaning noisy clinical text, extracting key medical entities (conditions and medications), and generating structured SOAP-style summaries as a prototype system.

The emphasis is on data understanding, domain-aware NLP tools, evaluation, and limitations, rather than production deployment or clinical use.

⚠️ Disclaimer: This project is for educational and research purposes only.
It is not intended for clinical use or medical decision-making.

The dataset contains synthetic or anonymized medical transcriptions and may include inaccuracies or incomplete information.
